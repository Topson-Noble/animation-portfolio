Game Animation Reel

A compilation of game-ready character animations developed across various projects.

Project Overview

This reel showcases gameplay animations developed across various game projects, focusing on responsive movement and clear character performance suitable for real-time gameplay. Covers locomotion systems, combat animations, idle behaviours, and cinematic cutscenes.

Technical Details

All animations are keyframe-animated, created in Maya, and implemented in Unreal Engine and Unity. Animations were exported as FBX and integrated using animation state machines and blend trees for smooth, responsive real-time playback.

Role & Focus

- Sole Animator on all featured shots.

- Designed locomotion sets, combat cycles, and cinematic sequences.

- Implemented and tested animations directly in Unreal Engine and Unity.

Objective

To showcase my ability to deliver polished, game-ready animations that feel responsive and natural — covering the full range of character states required in a production game pipeline.
